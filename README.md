# AWS IAM Labs

Hands-on IAM projects covering users, groups, roles, policies, and security 
best practices — from basic access control to cross-account roles and auditing.

## Projects

| # | Project | Concepts |
|---|---|---|
| 1 | [IAM Users & Groups](./Project-01-IAM-Users-Groups) | Users, groups, basic permissions |
| 2 | [Custom IAM Policy](./Project-02-Custom-IAM-Policy) | Least-privilege policy design |
| 3 | [EC2 + S3 IAM Role](./Project-03-EC2-S3-IAM-Role) | Roles, EC2-S3 integration, no hardcoded keys |
| 4 | [Cross-Account IAM Role](./Project-04-Cross-Account-IAM-Role) | Cross-account access, trust policies |
| 5 | [MFA Security](./Project-05-MFA-Security) | Multi-factor authentication |
| 6 | [IAM Password Policy](./Project-06-IAM-Password-Policy) | Account security baseline |
| 7 | [IAM Policy Simulator](./Project-07-IAM-Policy-Simulator) | Testing permissions before deployment |
| 8 | [IAM Billing Access](./Project-08-IAM-Billing-Access) | Scoped access to billing data |
| 9 | [CloudTrail IAM Audit](./Project-09-CloudTrail-IAM-Audit) | Auditing IAM activity |
| 10 | [Company IAM Design](./Project-10-Company-IAM-Design) | End-to-end IAM architecture for an org |

## Key skills demonstrated
- Principle of least privilege
- Role-based access (no hardcoded credentials)
- Cross-account and MFA security
- Auditing and policy testing
